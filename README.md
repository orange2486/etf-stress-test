# 台股 ETF 配置壓力測試器

👉 **線上使用：<https://tw-etf-stress-test.streamlit.app/>**（免安裝，手機也能開）

選幾檔台股 ETF 和比例，看你的配置在 2010 年以來歷次大跌中會怎樣：最大跌幅、最多少掉多少錢、
多久才回本、持有一段時間虧錢的機率，以及跟「同樣波動的 0050＋現金」比有沒有比較好。

- 可選：0050、006208、0056、00878、00679B，其餘放現金
- 價格：還原價（配息再投入、分割已調整），由臺灣證券交易所、證券櫃檯買賣中心公開的每日成交資料推算，
  並與 TEJ 台灣經濟新報資料交叉驗證（日報酬相關係數 1.000000，累積報酬差距 ≤ 0.22 個百分點）
- 成本：手續費 0.05%／邊、ETF 證交稅 0.1%（賣出）、滑價 1 檔／邊；現金利息以 0 計

這個工具來自研究報告《台股 ETF 投資迷思實證：用「事先鎖定、只跑一次」的回測檢驗常見說法》。

## 本機執行

```
pip install -r requirements.txt
streamlit run streamlit_app.py
```

## 資料來源與聲明

資料來源：臺灣證券交易所、證券櫃檯買賣中心（政府資料開放授權條款－第 1 版）。
資料截至 2026-09-24。本工具為歷史回測，**不構成任何投資建議**；過去的表現不代表未來。
